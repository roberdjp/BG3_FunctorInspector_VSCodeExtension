On hover over a functors line (StatsFunctors, SpellProperties, Boosts, Conditions, etc, etc), open a read-only popup that splits it on "and", "or", and ";". 
An "Open Beside" button opens the broken-down version in its own window for editing. 
Saving the "Beside" window updates the original line. 
Optional live-editing of "Beside" window. 

Install with CTRL-Shift-P "Install Extension from Location". Just select the "BGf_FunctorInspector_VSCodeExtension" folder.
